Autocompact no longer compacts a Pi agent a second time right after a compaction. A compaction record's `tokensBefore` (the size before the compaction) is no longer reported as the current context size. A compaction record that is newer, in file order, than every usage now makes `get_context_tokens()` return `None` until the next reply reports a real size: a `compaction` entry in the raw transcript or session file, a compaction `cost_snapshot` in the usage stream, or a compaction step in the common transcript. The idle timestamp is unaffected, and a suppressed size is logged at debug level with the agent and file path. The new `is_compaction_record` identifies these records.
