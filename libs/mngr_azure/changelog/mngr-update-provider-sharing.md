Hosts are now opened with a per-host VM-root client key (`keys/host_keys/<hex>/vps_ssh_key`) minted at create, instead of the provider-wide `keys/vps_ssh_key`; discovery reads the host id from the VM's `mngr-host-id` tag to pick that key. Existing hosts keep working through a read-only fallback to the old provider-wide key on the machine that created them. Destroying a deallocated VM now also removes the host's local key material and pin records.
