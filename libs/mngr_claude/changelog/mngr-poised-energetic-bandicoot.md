The release test that holds mngr's list of Claude Code background-task labels to the installed claude no longer fails when a newer Claude Code stops giving a label the Stop hook records as `OTHER` either way. Claude Code 2.1.329 dropped `memory import`, which turned the `test-claude-internals-latest` release job red and would have blocked the next mngr release. The test now fails when the installed claude gives a label mngr does not list, when the pinned claude does not give a label mngr lists, or when any other claude does not give a label the hook names; a missing `OTHER` label on a claude other than the pinned one is a pytest warning.
