- Sending a message to a Claude agent whose `/compact` was cancelled no longer turns the message into compaction instructions. Claude Code puts a cancelled `/compact` back into its input box, and the next send used to append to it, so the message started another compaction and was lost. The send now clears a leftover `/compact` (bare or with instructions) with Ctrl+E, Ctrl+U, confirms the input row is empty, and records a `cleared_restored_input_text` delivery event. Any other leftover draft is still kept and warned about, and so is a `/compact` the keys fail to clear.

- `ClaudeAgent.request_compaction` supports the new bounded message-lock wait and idle re-check: it takes the lock itself (raising `MessageLockTimeoutError` when the wait runs out), skips with `AgentNoLongerIdleError` when the agent is no longer idle since the expected moment, and only then sends `/compact`. A skipped compaction sends nothing and records nothing.
