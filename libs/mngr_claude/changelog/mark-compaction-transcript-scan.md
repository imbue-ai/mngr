The autocompact eligibility check no longer reads a Claude agent's whole transcript, twice, on every check. The idle timestamp and context token count now come from one backward scan of the transcript's tail, cached between checks, so an idle agent whose transcript has not changed costs one tail read that re-reads none of its complete lines. A 6.5 MB transcript used to peak at about 62 MB of memory per check, and a 52 MB one at about 500 MB; a check now reads tens of kilobytes. The values found are the same as before, except that a final line without a trailing newline is read once its newline arrives, and a record containing U+0085, U+2028 or U+2029, which the old parser split apart and skipped, is now read. The whole-text parsers `extract_latest_assistant_timestamp_from_jsonl` and `extract_context_tokens_from_jsonl` are replaced by the per-record `extract_assistant_timestamp_from_record` and `extract_context_tokens_from_record` and `ClaudeCompactionTranscriptScanner`.
