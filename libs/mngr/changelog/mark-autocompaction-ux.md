A compaction transcript reading can now say the context size is unknown because of a compaction. `CompactionTranscriptScanner` and `CompactionTranscriptReading` gain `is_context_size_unknown_since_compaction` and `is_context_size_settled()`: a harness scanner sets the flag when it meets a compaction record newer than every record reporting a token count, and the scan then stops looking for older token counts. The cache keeps that state between checks: compaction records appended after a cached token count replace the count with "unknown", and a token count appended after them restores a number.
