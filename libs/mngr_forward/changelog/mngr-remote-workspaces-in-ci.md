The paramiko reverse-tunnel client now supports credential-deferring SSH hosts (an outer host with no mngr-owned key, e.g. `DOCKER_HOST=ssh://...`): it verifies the host key against the user's own `~/.ssh/known_hosts` and lets paramiko run its default key lookup chain, matching the documented convention the pyinfra-based consumers of the same hosts already follow. Previously such hosts were always refused with "No known_hosts file at known_hosts" (a cwd-relative sibling of the empty key path), which broke the latchkey VPS gateway exposure in the latchkey e2e release test. Host-key checking stays strict: no trust-on-first-use is introduced.
