The autocompact eligibility check no longer reads a Codex agent's whole rollout or transcript files on every check. The idle timestamp and context token count now come from one backward scan of each file's tail, cached between checks, so an unchanged file costs no reads of its complete lines and a grown one is read only from where the last check stopped. The values found are the same as before, including skipping the task completion of a compaction turn named by a newer compaction record, except that a final line without a trailing newline is read once its newline arrives, and a record containing U+0085, U+2028 or U+2029, which the old parser split apart and skipped, is now read. The whole-text parsers `extract_latest_assistant_timestamp_from_jsonl` and `extract_context_tokens_from_jsonl` are replaced by `CodexCompactionTranscriptScanner` and the per-record `extract_context_tokens_from_record`.
