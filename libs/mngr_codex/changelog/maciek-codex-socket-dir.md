A codex agent's app-server socket lives in a directory of its own, `/tmp/mngr-codex-<hash>/app-server.sock`, which the daemon's launch creates at mode 0700. codex 0.157 and later refuse to bind a socket whose parent other users can write to, so on a host whose `/tmp` is world-writable without the sticky bit (Modal sandboxes are) the daemon never started and every codex create failed after its 45 s readiness wait.
