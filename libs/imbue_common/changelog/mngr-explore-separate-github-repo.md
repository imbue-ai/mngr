`imbue-common` no longer installs its heavy dependencies by default. `boto3`, `sentry-sdk`, `traceback-with-variables`, and `urllib3` moved to the new `sentry` extra, which `imbue.imbue_common.sentry` needs, and `cryptography`, `argon2-cffi`, and `httpx2` moved to the new `crypto` extra, which `imbue.imbue_common.secret_wrapping` and `imbue.imbue_common.owner_exec_client` need. A project that imports one of those modules declares the extra (`imbue-common[sentry]`, `imbue-common[crypto]`); everything else in the package installs as before.
