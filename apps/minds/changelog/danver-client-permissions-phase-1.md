A workspace's pages now need this computer's permission to use the microphone in the desktop app. The first request from a workspace opens a prompt in that window naming the workspace, with **Allow** and **Don't allow** remembered for the workspace on this computer by default; unchecking the remember box turns them into **Allow for this session** (good for the rest of the app run, in every window) and **Don't allow this time**. A remembered Don't allow refuses the request without the page being able to tell why, so Studio shows a toast in that window saying the microphone is blocked for the workspace on this computer and where to change it, once per workspace per run. A request from a popup window or any frame that is not the window's workspace is refused, as is every request while the backend cannot be asked.

The workspace options panel's Permissions tab gains a last section, **Client permissions**, with one row per permission (the microphone, for now) and a four-way control: Use the default (Ask), Ask, Allow, Don't allow. The answers apply only on this computer: they never sync, never reach the workspace or another computer, and the section renders even when the latchkey gateway cannot be reached. They live per install at `workspace_install_settings/<workspace>.json` in the state directory and are forgotten with the workspace. Nothing changes in a browser, and the docs say why: a share link opened with no Studio chrome is gated by the browser's own prompt, per workspace and per person, while Studio's own app opened in a browser has no per-workspace gate yet, since browsers key a delegated grant to the top-level origin. The desktop-app, latchkey-permissions and security-boundaries-audit docs describe the gate, the tab section and the narrowed default.

For maintainers: the settings model gains an override kind, install per workspace (`SettingOverrideKind.INSTALL_WORKSPACE`), carried by the new `WorkspaceInstallSettings` record and resolved ahead of the install's own value; `client_permissions` is the first setting declared with it.
