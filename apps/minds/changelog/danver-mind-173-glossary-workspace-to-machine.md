Renamed the core concept from "workspace" to "machine" in the minds glossary (docs/workspace/glossary.md). The machine entry now states that "machine" is the name going forward, that "workspace" is a deprecated previous name being sunset (surviving in literal identifiers and not-yet-migrated code and docs), and that a machine is not an agent -- an agent is a distinct mngr process running inside a machine. Every other entry's prose adopts the new noun; the glossary's structure is unchanged, and casual uses of "machine" meaning physical hardware become "computer" so they cannot collide with the new term. The template entry's "mind" noun is retired in the same pass: the builder of a template's creations is the user, working in their machine, and it is another machine that is created from or adopts a template.

The behaviors corpus is migrated to the same vocabulary: every scenario, rule, overview, and Examples table now says machine, and the one identity tag carrying the old word is renamed (home-page.lists-workspaces -> home-page.lists-machines) together with its witnesses marker. The corpus-mandated home-page copy "Discovering workspaces" -- a leftover the July UI copy rename could not touch because the corpus pinned it -- becomes "Discovering machines" in the corpus, the LandingPage, and the witness notes.
