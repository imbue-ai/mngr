Added the workspace command contract (`workspace_programs/workspace_command_contract.py`, documented in `docs/workspace-command-contract.md`). It is one versioned declaration of every script and console script Imbue Studio runs inside a workspace's template: `message_chat.py`, `seed_welcome_chat.py`, `collect_bug_report_diagnostics.py`, `background_tasks.py`, update-self's `run-status`, `workspace-layout open` and `agent-access`. For each it gives the arguments, exit statuses and output the app relies on, plus the template paths the app checks for. The app and its workspace programs now build those commands' arguments through the contract, and a unit test checks every argument shape against it. The contract is also published as `workspace_command_contract.json`, which default-workspace-template vendors to check its own scripts against on every change.

When `message_chat.py` rejects arguments the contract declares, Studio and the update dispatcher still fall back as before, and now also log a warning naming the script and the contract version (the dispatcher in its `dispatcher.log`).
