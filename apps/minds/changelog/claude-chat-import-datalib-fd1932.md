Settings has a new "Experimental features" section with an "Opt into experimental features" checkbox, saved with the account so it follows you across devices. Until you answer, it is on for accounts on the `ally` plan and off otherwise. The workspace profile snapshot carries the result (`experimental_features_enabled`), so a workspace can offer features still being tried out only to accounts that have them on. The desktop reads each unanswered account's plan at most every five minutes, and a failed read keeps the last answer, so a connector outage never turns them off.
