Added resource warnings for the computer Imbue Studio runs on, with the same rules and words as the workspace's resource gauge. When disk, memory or CPU runs low, a pill in the titlebar says so in words ("Disk space is low"); clicking it opens Settings > This computer > Resource warnings, which shows each resource's current use ("400 GB of 926 GB disk", "32 GB of 64 GB RAM", "40% of CPU") above its warning switch and level. The disk warns at 10 GB left or when it is on course to fill within 15 minutes; memory and CPU warnings are opt-in.
