The release runbook also stamps the workspace template's changelog once that changelog has per-release sections: after the template's mngr pin lands, the release's section goes on the tip of the template's main branch in a commit of its own, which is pushed only when its pin matches the release's, checked, and tagged. A branch that carries a stamp is never merged, except a patch cut's template branch, which is merged back by a direct push to the template's main branch. The app's release section can end with a link to the template's changelog at the same tag.
