# Get help

Understanding this behavior corpus calls for the behaviors skill; consult it when reading this file.

Get help is the desktop client's report-a-bug dialog.
It floats over the surface it was opened from, and when it is about a workspace, that workspace stays on screen behind it.
An *agent report* is a Get help dialog that an agent inside a workspace opened on the user's behalf, pre-filled with the agent's own description of a problem.
The agent never sends the report itself: the user reviews it and either sends it or closes it.

## Out of scope

- What a sent report contains and where it is delivered.
- The "have an agent help" mode of the dialog the user opens themselves.
