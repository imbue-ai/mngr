# Third-party artwork shipped with Imbue Studio

Most of the brand marks in this directory come from two Iconify icon sets,
copied verbatim: each file is one icon body from the set, wrapped as a
standalone SVG document. The rest come from simple-icons, with the brand's
fill written in, or straight from the vendor's own brand kit, as the sections
below record. `README.md` records which file came from which source.

## simple-icons — CC0 1.0

Source: <https://github.com/simple-icons/simple-icons>, npm package v13.21.0.
Dedicated to the public domain under CC0 1.0. Five marks come from this set,
`calendly`, `umami`, `linktree`, `webflow` and `wix`, because neither

## Vendor brand kits

Three services' marks come directly from artwork the vendor publishes for
exactly this kind of identifying use -- two because they appear in no vetted
icon set, and Vercel because no set carries the white variant its black
triangle needs on the dark theme:

- `ngrok.svg` / `ngrok-on-dark.svg`: the "n" symbol (`ngrok-n-dark.svg` /
  `ngrok-n-white.svg`) from the official brand kit at
  <https://ngrok.com/brand> (`ngrok-logos.zip`). Copyright ngrok.
- `ramp.svg` / `ramp-on-dark.svg`: the Ramp symbol
  (`Ramp-Symbol-RGB-Slate-0125.svg` / `Ramp-Symbol-RGB-White.svg`) from the
  official press kit at <https://ramp.com/press>. Copyright Ramp Business
  Corporation.
- `vercel-mcp.svg` / `vercel-mcp-on-dark.svg`: the Vercel triangle
  (`vercel-triangle-black.svg` / `vercel-triangle-white.svg`) from the brand
  assets at <https://vercel.com/geist/brands>, served from
  `assets.vercel.com/image/upload/front/assets/design/`. Copyright Vercel.

These files are the vendor's artwork unaltered apart from mechanical
normalization recorded in `README.md` (root sizing attributes rewritten as an
equivalent `viewBox`; a CSS-class fill rewritten as the same fill attribute).
Colors and path data are unchanged. Brand-kit assets are not CC-licensed; they
are used, as the kits intend, solely to identify the vendor's service.
