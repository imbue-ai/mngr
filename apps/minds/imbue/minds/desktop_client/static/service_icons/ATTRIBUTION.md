The brand marks in this directory come from two Iconify icon sets. They are
copied verbatim: each file is one icon body from the set, wrapped as a
standalone SVG document. `README.md` records which file came from which icon.

## Vendor brand kits

Two services appear in no vetted icon set, so their marks come directly from
artwork the vendor publishes for exactly this kind of identifying use:

- `ngrok.svg` / `ngrok-on-dark.svg`: the "n" symbol (`ngrok-n-dark.svg` /
  `ngrok-n-white.svg`) from the official brand kit at
  <https://ngrok.com/brand> (`ngrok-logos.zip`). Copyright ngrok.
- `ramp.svg` / `ramp-on-dark.svg`: the Ramp symbol
  (`Ramp-Symbol-RGB-Slate-0125.svg` / `Ramp-Symbol-RGB-White.svg`) from the
  official press kit at <https://ramp.com/press>. Copyright Ramp Business
  Corporation.

These files are the vendor's artwork unaltered apart from mechanical
normalization recorded in `README.md` (root sizing attributes rewritten as an
equivalent `viewBox`; a CSS-class fill rewritten as the same fill attribute).
Colors and path data are unchanged. Brand-kit assets are not CC-licensed; they
are used, as the kits intend, solely to identify the vendor's service.
